# tools/

Переиспользуемые утилиты — то, что пишется раз и используется во многих сборках. **Главная ценность за годы накопления.**

## Идеи кандидатов (создавать по мере необходимости)

- **`param-diff/`** — сравнить два `.param` файла из Mission Planner, показать только различия по параметрам
- **`log-analyzer/`** — парсить ArduPilot `.bin`-логи, искать аномалии вибраций / переусилий / выпавших EKF check'ов
- **`crsf-monitor/`** — снифер CRSF-телеметрии через USB-UART адаптер, разбор Link Statistics
- **`elrs-config-export/`** — снять текущие настройки ELRS Web UI через API, сохранить `.json` для версионирования в `templates/elrs/`
- **`mp-mission-validator/`** — статическая проверка `.waypoints` миссий (геозоны, высоты, последовательность команд)

## Соглашения

- Каждая утилита — отдельная подпапка с `README.md`.
- Если Python — со своим `pyproject.toml` и `verify.ps1` (по шаблону `u1u2-bridge`).
- Если однострочник / простой bash — может быть просто скрипт с заголовком-документацией.
- Если нужен GUI — Tkinter или textual, не Electron (нам не нужны 200MB бинари).

## Скил для этого раздела

В зависимости от утилиты:
- Python-парсеры, анализаторы — `embedded-programmer` (общий Python)
- Утилиты, работающие с MAVLink детально — `mavlink-px4-expert`
- Утилиты для конкретно ArduPilot формата параметров/логов — `ardupilot-expert`, раздел `references/diagnostics.md`
