# Загрузка карты DEM-высот в Mission Planner

## Что такое DEM

DEM (Digital Elevation Model) -- цифровая модель рельефа. Mission Planner использует данные **SRTM** (Shuttle Radar Topography Mission) от NASA с разрешением 30 м (Level 1) или 90 м (Level 3) для отображения высот над уровнем моря.

---

## Способ 1. Автоматическая загрузка (встроенная в Mission Planner)

Mission Planner автоматически скачивает и кэширует тайлы SRTM при работе с картой.

1. Откройте **Mission Planner** и перейдите на вкладку **FLIGHT PLAN**.
2. Переместите карту в нужный район -- в нижней панели отобразятся координаты курсора и **высота ASL** (Above Sea Level) из данных SRTM.
3. Данные кэшируются локально на диск в папку `srtm` внутри директории Mission Planner и доступны офлайн после первой загрузки.

> **Примечание:** для автоматической загрузки требуется интернет-соединение при первом обращении к новому тайлу.

---

## Способ 2. Загрузка на SD-карту автопилота

Для работы режима **Terrain Following** (следование рельефу) данные высот должны быть на microSD-карте автопилота.

### Вариант A -- через MAVLink (автоматически)

1. Подключите автопилот к Mission Planner по **USB** или **телеметрии**.
2. Дождитесь **GPS-фиксации** (GPS lock) -- это обязательно.
3. Загрузите миссию на автопилот (кнопка **Write WPs**).
4. Mission Planner автоматически передаст необходимые тайлы рельефа в директорию `APM/TERRAIN` на SD-карте.

### Вариант B -- через веб-утилиту terrain.ardupilot.org

1. Перейдите на сайт **https://terrain.ardupilot.org**.
2. Выберите район полёта на карте.
3. Скачайте файлы `.DAT` с данными высот.
4. Скопируйте файлы вручную на microSD-карту автопилота в папку `APM/TERRAIN`.

---

## Способ 3. Загрузка пользовательских DEM-данных (GeoTIFF / .hgt)

Если вам нужны данные более высокого разрешения или из альтернативных источников:

### Шаг 1. Скачать DEM

| Источник | Разрешение | Формат | Ссылка |
|----------|-----------|--------|--------|
| USGS Earth Explorer | 30 м | GeoTIFF / .hgt | https://earthexplorer.usgs.gov |
| OpenTopography | 30 м | GeoTIFF | https://opentopography.org |
| Copernicus DEM | 30 м | GeoTIFF | https://spacedata.copernicus.eu |

Для USGS Earth Explorer:

1. Зарегистрируйтесь на сайте.
2. Во вкладке **Search Criteria** задайте координаты интересующей области.
3. Во вкладке **Data Sets** выберите **Digital Elevation** -> **SRTM**.
4. Нажмите **Results** и скачайте нужный тайл.

### Шаг 2. Обработать в QGIS (при необходимости)

Если данные в формате GeoTIFF и требуется конвертация или обрезка:

1. Откройте QGIS.
2. Перетащите файл `.tif` в окно проекта.
3. Используйте **Raster** -> **Extraction** -> **Clip Raster by Extent** для обрезки по нужной области.
4. Экспортируйте в нужный формат.

> Также можно использовать плагин **SRTM-Downloader** в QGIS для скачивания SRTM-тайлов напрямую.

## Настройка Terrain Following в Mission Planner

После загрузки данных высот на автопилот можно настроить режим следования рельефу:

1. Перейдите на вкладку **FLIGHT PLAN**.
2. При создании точек маршрута (waypoints) выберите тип высоты **"Terrain"** вместо "Relative" или "Absolute" в выпадающем списке **Alt** (правая панель).
3. Задайте высоту -- она будет интерпретироваться как высота **над рельефом** (AGL), а не над точкой HOME или уровнем моря.
4. Убедитесь, что параметр `TERRAIN_ENABLE = 1` установлен в **CONFIG/TUNING** -> **Full Parameter List**.

### Проверка графика высот

В нижней части экрана **FLIGHT PLAN** отображается профиль высот миссии. Если график показывает нулевые значения (плоскую линию), значит данные SRTM не загрузились -- проверьте интернет-соединение и перезагрузите Mission Planner.

---

## Параметры автопилота для Terrain Following

| Параметр | Значение | Описание |
|----------|----------|----------|
| `TERRAIN_ENABLE` | 1 | Включить работу с рельефом |
| `TERRAIN_SPACING` | 100 | Расстояние между точками сетки рельефа (м) |
| `WPNAV_RFND_USE` | 1 | Использовать дальномер для уточнения высоты (если есть) |
